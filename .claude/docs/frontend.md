# Frontend

Static site, no bundler. Classic `<script>` tags share globals (top-level `let`/`const`/functions are visible across files). Load order in `index.html`: ethers (CDN, SRI-pinned 6.13.4) → `config.js` → `chain.js` → `main.js` → `perps.js`.

| File | Responsibility |
| --- | --- |
| `src/config.js` | `window.PERPS_CONFIG = {address, chainId, deployBlock, rpcUrl, owner, abi}`; generated by deploy; `null` stub when undeployed |
| `src/chain.js` | `Chain` — only place that talks to the contract. Reads via JsonRpcProvider, writes via MetaMask `BrowserProvider`. Prices → cents, amounts → MON numbers |
| `src/main.js` | Screens/nav, wallet connect + network switch, Gemini reference feed, charts, order ticket (`entryPrice`, `liquidationPrice`, `estimate`, `#trade` handler) |
| `src/perps.js` | Syncs chain markets into the shared `markets` array, `refreshAll()` loop (15s), My positions, House dashboard, owner "List this market on-chain" |
| `src/perps.css` | Styles for positions/house tables and KPIs |

## Screens

Overview · Markets (on-chain perps first, Gemini reference rows hidden once listed) · Trade (ticket) · My positions · House (nav link visible only to the contract owner; page itself is read-only data for anyone).

## Conventions and traps

- Market objects: on-chain ones carry `chainIdx`, `index` (oracle), `price` (mark), `longOI`, `shortOI`, `oiCap`, `skew`, `fundingPerDay`. Gemini ones carry `symbol`, `expiryISO`.
- Ticket math must mirror the contract: entry from **index** + skew·netOI-after/cap; slippage limit = entry ± 0.5¢ clamped to 0–100.
- Hooks `main.js` calls if defined by `perps.js`: `onMarketSelected(m)`, `onWalletChange()`, `refreshAll()`.
- Escape anything from outside with `escapeHTML` before `innerHTML`.
- The wallet network comes from `PERPS_CONFIG.chainId` (31337 local, 10143 Monad testnet).
- Tests stub the DOM; any new `$("#id")` or `$$("selector")` should keep working with the stub in `tests/app.test.js` (unknown selectors return `[]`).
