# Impact Perps — team brain

Perps on prediction markets, on Monad. Traders go long/short the probability (0–100¢) of an outcome listed on Gemini/Polymarket, with MON margin and up to 25× leverage. A house vault is the counterparty. Prices come from a signed multi-venue oracle; markets settle at exactly 0¢ or 100¢ when the venue resolves.

**Status: hackathon / testnet only, unaudited. Never imply it is safe for real funds.**

## Rules of the road

1. **Never put private keys, mnemonics or `.env` contents in chat, files, commits or logs.** Keys come from the environment. Ask the human to run anything that needs their funded key.
2. **Modular commits.** One concern per commit, conventional prefix (`feat(contracts):`, `fix(app):`, `test:`, `docs:`). End messages with the Co-Authored-By trailer the harness gives you.
3. **Edit files with the Edit/Write tools.** No ad-hoc Python/sed rewrite scripts against source files.
4. **Contract changes need tests.** Run `forge test` before committing; `openPosition` is `(marketId, isLong, leverage, limitPrice)` — any new caller must pass a slippage limit.
5. **`src/config.js` is generated by `scripts/deploy.mjs`** (address + ABI). The committed version is a null stub. Do not commit a config that points at a local chain.
6. **Set `RPC_URL` explicitly.** `scripts/lib.mjs` defaults to Monad testnet; forgetting it sends a real transaction attempt there instead of to anvil.
7. **Prices:** contract uses 1e18 = 100%. The UI uses cents (0–100). Money is MON (18 decimals) as JS numbers only for display.
8. **Entry price = oracle index + skew impact**, not the mark. Use `market.index` for entry math, `market.price` (mark) for display.
9. **Untrusted text** (market names, Gemini fields) must go through `escapeHTML` before `innerHTML`.
10. Report honestly: if something wasn't run or verified, say so.

## Definition of done

`forge test` and `npm test` green, behavior checked in the browser against local anvil for UI changes, docs updated if a rule/interface above changed, commits modular.

## Known sharp edges

- All oracle signer keys can run in one keeper process (centralized trust). Venue → market mapping is manual (`scripts/keeper.markets.json`).
- Keeper finalizes a market as soon as every quoting venue reports a resolution. Real data can settle a test market within minutes of listing.
- `SIGNER_KEYS` and `SIGNER_VENUES` must have equal length and match the on-chain signers.
- Log history uses bounded `eth_getLogs` lookbacks; an indexer is needed for real history.
